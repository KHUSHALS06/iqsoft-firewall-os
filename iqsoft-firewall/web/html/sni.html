Application control

Block an app by the site names it uses. Allow lets an app through even if a DNS filter list blocks it. Not managed removes your choice. Turn on site-name filtering in the Settings tab for this to work.

Site rules

A rule for a domain also covers all its subdomains.

Site-name filtering

Reads the site name at the start of each HTTPS connection and blocks it by the rules and app choices. Changes take effect when you press Save.
