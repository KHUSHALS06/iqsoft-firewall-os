System information

Change password

Choose a new password for your account. You will be signed out afterwards.

Download a backup

A single file with every setting on this firewall: rules, NAT, network, VPN, filters and user accounts. It contains password hashes and VPN keys, so keep it somewhere safe.

Restore from a backup

The file is checked first and then stored. It replaces the current configuration the next time the firewall service starts, so nothing changes until you reboot. The configuration it replaces is kept on the disk as firewall.db.before-restore.

Reboot

Restart this firewall. Traffic through it stops for a minute or two. Saved rules are loaded again when it comes back.

Shut down

Power this firewall off. You will need physical access or a remote power control to turn it on again.
