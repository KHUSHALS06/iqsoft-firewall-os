User accounts

Each person signs in with their own account. What they can see and change depends on the role you give them. A Super Admin can manage everything; an Admin can create users and roles within their own rights.

Roles

A role is a set of ticks. For every feature you decide whether the role may view it, create new entries, edit existing ones or delete them. Changes apply to people who are already signed in.
