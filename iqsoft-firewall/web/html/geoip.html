Block a country

Policies are saved here and put into effect with the firewall rules. After changing them, open Firewall Rules and apply. A country only blocks traffic once its address list is loaded in the Country lists tab. Private and local address ranges are never blocked.

Load a country address list

Replaces the list for that country. Use one address range per line, for example 203.0.113.0/24. IPv4 and IPv6 can be mixed. If the list is refused, the old list stays.
